# What the assistant says when it finds no answer

## When it doesn't understand what was written
reply: unclear

I didn't understand that. Can you write it again with a little more detail? For example: "how do I withdraw to my bank". If you'd rather, use **Talk to a person**.

## When it can read it but doesn't know the answer
reply: not-found
keywords: problem, problems, issue, issues, complaint, claim, dispute, urgent, never

I don't have information about that yet. Can you ask it another way? If I still don't know, I'll pass you to a person from support.

## When it understands only a part
reply: suggestions

I think I understood only part of that. Are you asking about one of these? If not, write it another way.
